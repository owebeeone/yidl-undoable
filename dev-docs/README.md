# Developer Documents

- [Undoable design](UndoableDesign.md): proposed API, field policies, sparse
  storage, nested-object visibility, failure contracts, generation architecture,
  and implementation checks.
- [Current checkpoint](CurrentProgramCheckpoint.md): review object, verdicts,
  implementation boundary, and next action.
- [Experiment ledger](ExperimentLedger.md): elapsed time, measured token usage,
  estimated API-equivalent cost, and quality evidence.

Verbatim design and runtime review reports and merged remediation plans are
filed here under the `UndoableDesign` and `UndoableImplementation` names.
Runtime acceptance has its own exact tuple and dual verdicts.

- [TDD implementation plan](UndoableImplementationPlan.md).
- [Actual TDD evidence](TddEvidence.md): timestamped red/green/refactor tranches.
- [Implementation mapping](ImplementationDraft.md): delivered design coverage.
- [Independent verification](VerificationEvidence.md): version matrix and wheels.

- [Experiment results](ExperimentResults.md): final delivery, elapsed time,
  observed tokens, API-equivalent cost, actual-billing limits and quality.
- Final runtime [Code/Surface review](UndoableImplementation-ReviewCode-6.md)
  and [State review](UndoableImplementation-ReviewState-6.md), both GO.
