# Runnable examples

Install the package, then run `python examples/first_use.py`. The remaining
programs accompany the matching public guides: collections, field boundaries,
object graphs, dependent fields, validation and snapshots. Each is self-contained.

Development tests and benchmark probes live elsewhere; these programs teach
normal application use. `dev-docs/documentation/verify_examples.py` executes all
examples and the complete guide blocks against the active installation.
